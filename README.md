# Edi

I like taking desktop games, tools, and plugins and figuring out how to make them run on Android, Linux, or wherever else they weren't originally built to work. 

Everything on this profile is **vibe coded**—I lean heavily on AI to prototype fast, jump into unfamiliar languages or engines, patch weird compatibility bugs, and get working builds out the door without getting stuck in boilerplate.

---

### What You'll Find Here

* **Game & Engine Ports:** Adapting PC and browser games for mobile and handhelds—hooking up touch controls, fixing broken shaders or viewport scaling, and packaging standalone APKs.
* **Porting & Build Tools:** CLI tools and scripts that automate the tedious parts of porting, like asset extraction, decompilation, code injection, and headless builds.
* **Plugins & Experimental Patches:** Porting server mods, testing out WebAssembly plugins, and patching host binaries when stock APIs don't do what I need.

---

### Usual Stack

* **Languages:** Python, Rust, C#, Lua, JavaScript, Bash, HLSL/ShaderLab
* **Platforms & Runtimes:** Android, Linux / Steam Deck, Unity, LÖVE 2D, WebAssembly (WASI)
* **Workflow:** Vibe coding, rapid prototyping, reverse engineering, trial and error
